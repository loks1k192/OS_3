# OS_3

OS_3 — лабораторная работа по операционным системам: изучение взаимодействия процессов на языке C, запуск дочерних процессов и обмен данными между ними.

Состав репозитория
- `parent.c` — исходный код родительского процесса  
- `child.c` — исходный код дочернего процесса  
- `Makefile` — автоматизация сборки  
- `doc/` — отчёт, пояснения и дополнительные материалы  
- `.gitignore` — игнорируемые файлы для git

Как использовать
1. Откройте терминал в папке OS_3.
2. Выполните команду:
   ```
   make
   ```
3. Запустите полученные исполняемые файлы для демонстрации взаимодействия процессов.

Цели лабораторной работы
- Освоить создание и запуск дочерних процессов в C.
- Научиться организовывать обмен данными между процессами.
- Проанализировать особенности работы процессов в ОС.
